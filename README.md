A program that writes one image summing up the world news of Wednesday 18 November 2026 — the U.S.–Iran escalation in the Gulf, America losing measles-free status, Ukraine's Crimea bridge strikes, COP31's final days, and Israel's new Knesset speaker — to /output/entry.png. The image was composed for this bounty (a newspaper front page drawn with PIL around an AI-generated globe illustration) and is copied byte-for-byte by main.py; compose.py is the build-time script that drew it.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
