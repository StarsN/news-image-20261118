A program that writes one image summing up the world news of Wednesday 18 November 2026 — Iran striking U.S. bases in Bahrain and Kuwait as the Gulf war widens, Trump landing in Shenzhen for the first-ever U.S.–China–Russia trilateral, Anthropic pricing its record IPO at $83, COP31's final days in Antalya, and Nvidia beating forecasts as the SEC opens a probe — to /output/entry.png. The image was composed for this bounty (a newspaper front page drawn with PIL around an AI-generated globe illustration) and is copied byte-for-byte by main.py; compose.py is the build-time script that drew it.

Round 2 (2026-11-19): refreshed with the full 18 November news day. Stories first reported on 17 November (measles status, Kerch bridge, Knesset speaker, Prague crash, Biden memoir, Russia–France warning) were removed after date checks.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
